# PitchPulse

Dashboard παρακολούθησης ποδοσφαιρικών προπονήσεων, με ελληνικό περιβάλλον και προσαρμογή για κινητό.

Περιλαμβάνει προσωπικό καλωσόρισμα, απόσταση, ταχύτητα, σπριντ, ζώνες έντασης, heatmap, διαδρομή και ιστορικό προπονήσεων. Οι μετρήσεις είναι δοκιμαστικά δεδομένα. Ο συγχρονισμός με πραγματικό tracker παραμένει υπό ανάπτυξη.

## Εκκίνηση

Απαιτείται σύγχρονη έκδοση Node.js συμβατή με το Vite 7.

```sh
npm ci
npm run dev
```

Άνοιξε τη διεύθυνση που εμφανίζεται στο terminal.

## Δοκιμή σε κινητό στο ίδιο Wi-Fi

```sh
npm run dev -- --host 0.0.0.0
```

Άνοιξε από το κινητό τη διεύθυνση `Network` που εμφανίζει το Vite. Ο υπολογιστής και ο server χρειάζεται να παραμένουν ανοιχτοί.

## Build

```sh
npm run build
npm run preview
```

Το build δημιουργείται στον φάκελο `dist/`.

## Αρχεία

- `src/main.jsx`: εφαρμογή React και αλληλεπιδράσεις.
- `src/index.css`: εμφάνιση και διάταξη για υπολογιστή και κινητό.
- `football_tracker_dashboard_demo.html`: αυτόνομη έκδοση του demo, που ανοίγει και απευθείας στον browser.
- `index.html`: αρχική σελίδα της εφαρμογής React.

Η αυτόνομη έκδοση HTML και η έκδοση React ενημερώνονται χωριστά.

Στην πρώτη είσοδο η εφαρμογή ζητά το όνομα του χρήστη. Το αποθηκεύει τοπικά στον συγκεκριμένο browser και επιτρέπει την αλλαγή του από το μολύβι δίπλα στο καλωσόρισμα.

## Online πρόσβαση

Η φιλοξενία του κώδικα στο GitHub μπορεί να ακολουθηθεί από ενεργοποίηση του GitHub Pages ή άλλη υπηρεσία hosting, για δοκιμή και από δεδομένα κινητού ή διαφορετικό Wi-Fi.
